# placemoir.app

The marketing site for **Placemoir**, a private journal for the places you visit. Plain static HTML, CSS and a little JavaScript, published with GitHub Pages from the root of `main` by `.github/workflows/pages.yml` (Settings → Pages → Source must be "GitHub Actions"). There's no build step.

## Preview

```bash
python3 -m http.server 8811
```

Then open http://127.0.0.1:8811. GitHub Pages serves `404.html` for missing paths; the Python server doesn't.

## Conventions

- Brand: Field Journal. Paper and ink, moss accent, plum used sparingly, Newsreader italic for titles (never roman), Karla for text, Plex Mono for dates and small eyebrows.
- Liquid Glass (`.glass`, `.glass-tint`) is for controls and floating chips only. Content sits on Page cards. Glass falls back to solid Page under Reduce Transparency.
- Every color is a token with a light and a dark value. Screenshots are `<picture>`s with a `(prefers-color-scheme: dark)` source marked `data-theme-dark`; the logo SVGs use `.only-light` / `.only-dark`.
- The Content Security Policy allows only same-origin scripts, styles, fonts and images, with no inline styles or scripts. Guide pages (`guides/`) also allow Apple's MapKit JS hosts, for their map; nothing else does. The other exception is Cloudflare Web Analytics, which Cloudflare injects because the site is proxied (static.cloudflareinsights.com and cloudflareinsights.com). No cookies or other third-party requests.

- Cloudflare caches CSS and JS for four hours, so stylesheets and scripts are linked with `?v=<date>`. When you change `css/` or `js/`, bump that value in every page (`grep -l '?v=' *.html`), or the live site mixes new HTML with old CSS.

## Translations

The English pages at the root are the source. `tools/i18n.py` (standard library only) reads their text on its own, gettext style: each run of text, with any inline tags such as `<strong>` or `<a>` inside it, plus `alt`, `aria-label`, `title`, the description and social meta tags, and the `data-label*` / `data-valuetexts` strings that `theme.js` and `rating.js` read. The English text is the key in `i18n/<lang>.json`, so there's nothing to mark up when you write English copy.

```bash
python3 tools/i18n.py build    # rebuild every language folder, the hreflang links, the language list and the sitemap
python3 tools/i18n.py check    # list missing translations (exit 1 if any)
python3 tools/i18n.py sync     # after changing English copy: add new strings as null, drop unused ones
python3 tools/i18n.py review /path/to/folder   # side-by-side English/translation pages for reviewers
```

- After you change English copy on a translated page (only `index.html` for now), run `sync`, fill in the new strings, then `build`. A string without a translation falls back to English, and `check` lists it.
- Each language file has `"status": "draft"` or `"reviewed"`. Draft pages are built and served, with `noindex`, so reviewers can read them on the live site, but they stay out of the language list, hreflang and the sitemap until a native speaker has checked them and the status is `reviewed`. With no reviewed language, the English pages show no language list or globe at all.
- Translated pages keep US-only facts out: no US prices (the App Store shows the local one). Legal pages, the archive spec and other inner pages stay in English for now; translated pages link to them.
- Japanese and Traditional Chinese use the system fonts (Hiragino, PingFang TC) and are never set in italic; see the end of `site.css`. Each language uses Apple's own localized black badge from `images/badges/app-store-<lang>.svg` (from Apple's marketing badge kit, unaltered; Latin American Spanish uses Apple's Mexico badge). A language without one falls back to the English badge.
- Don't edit inside the `<!-- i18n:... -->` markers in the English pages; `build` rewrites them.

## App Store links

Placemoir 1.0 went live on the App Store on November 6, 2026 (app ID `6829224969`).

- Every page has `<meta name="apple-itunes-app" content="app-id=6829224969">` for Safari's Smart App Banner.
- Store links go straight to `https://apps.apple.com/app/placemoir/id6829224969?pt=121730518&ct=<campaign>&mt=8`. `pt` is the Tweeting Birds provider token and `ct` names where the click came from, so App Store Connect › App Analytics › Campaigns shows which link drives downloads. Campaigns in use: `website-nav`, `website-hero`, `website-download`, `website-faq`, `press`. Use a new `ct` for each new placement and for social posts (`bsky`, `threads`, `ig`, `email`).
- The badge is Apple's official black “Download on the App Store” SVG (`images/app-store-badge.svg`, the same file as quipsapp.com). Don't recolor or redraw it; keep it at least 40px tall.
